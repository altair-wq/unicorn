# Dinner for Two

A one-page prototype (B144 class assignment) that helps two people agree on a dinner plan.

**Run it:** open `index.html` in any web browser. No install or server needed.

**How it works:**
- Each person taps a day, a cuisine and enters a max budget per person.
- Day must match for both people.
- Cuisine matches if it's the same, or if either person picks "Any".
- Shared budget is the lower of the two budgets.
- Conflicts show one-tap fixes like "Both pick Saturday".
- The meeting map is a sketch, not real streets: drag each person's pin and the dinner spot
  moves to a fair point in between, with walking routes and rough times (1 block ≈ 2 min).
